# 微积分 Python 教学程序（Calculus Python Tutor）

一个可交互的微积分入门教学程序，内容对应上传的英文讲义第 1–2 章：函数与极限、导数与求导法则。
所有计算在本机由 SymPy 完成，不联网、不上传任何数据。

## 启动方式

**方式一：双击 `run.cmd`**（推荐。本机已有依赖直接启动；换台电脑首次双击会自动联网安装一次依赖，之后离线可用）

**方式二：命令行**

```bat
cd calculus_python_tutor
python -m pip install -r requirements.txt
python -m streamlit run calculus_tutor.py
```

启动后在浏览器打开 http://localhost:8501 （双击 `run.cmd` 时窗口里也会打印这个地址）。按 Ctrl+C 或关闭窗口即可停止服务。

启动脚本带 `--server.address localhost`，服务只监听本机回环地址，同一局域网内的其他设备无法访问，也不会收集使用统计。

## 文件结构

| 文件 | 作用 |
|---|---|
| `calculus_tutor.py` | Streamlit 界面：14 个课节页面、交互实验室、练习题 |
| `calculus_engine.py` | 数学引擎：解析、求导、极限、定义域、隐函数求导、绘图（不含界面代码，可独立测试） |
| `test_tutor.py` | 200 项无头测试，覆盖解析、数学正确性、解题内容渲染与每个页面的真实运行 |
| `requirements.txt` | 依赖清单 |
| `run.cmd` | Windows 一键启动 |
| `_libs/` | 本机已安装好的依赖库（无需联网即可运行） |

## 每个主题都配有解题方法

- **11 个课节**各自包含「How to solve it, step by step」通用解题步骤（共 68 步）。
- **27 道完整例题**逐步作答（共 142 个解答步骤），每题都标注答案与常见错误。
- **实验室 10 种模式**每种都附带该题型的手算方法，随下拉选择自动切换。
- **练习题页**提供 6 类题型的解法速查与通用解题流程。
- 所有例题的最终答案都用 SymPy 独立重新推导校验过，包括定义域、极限、各类导数、
  三条不同曲线的隐函数求导及其在具体点上的斜率。

## 讲义未覆盖、这里额外补上的能力

- **学生友好的表达式解析**：`2x`、`x^2`、`x²`、`√x`、`sin^2(x)`、`|x|`、`f(x) = ...` 都能直接识别
- **报错会说清楚怎么改**：括号不配对会告诉你是几个开括号对几个闭括号，而不是丢一句 "invalid syntax"
- **求导步骤按结构命名法则**：自动识别这是乘积法则还是商法则、外层是否还要接链式法则，再用 `sp.diff` 给出可验证的正确结果
- **符号解与数值解互相校验**：用对称差商 `[f(a+h) − f(a−h)] / 2h` 复核解析结果，两者一致才算通过
- **极限会诚实说"不存在"**：左右极限不相同时明确报告不存在，而不是给出一个错误数字
- **隐函数求导是真求导**：对学生输入的方程两边逐项求导再解出 dy/dx，不是把答案写死在题目里

## 已知取舍

- 绘图用固定采样点数（900），高频振荡函数在极窄区间内可能显示不全。
- 渐近线的断开是启发式判断：跳跃幅度远超画面高度且跨零时才断开。个别极端函数可能在渐近线处仍留一条连接线。
- 定义域分析对分段函数、含参函数的覆盖有限，遇到 `solveset` 无法处理的情形会退回"未找到限制"。
- 数值校验采用相对误差 2e-4；在函数不可导的点上两者不一致属于预期行为，程序会提示而非报错。

## 如何分享给别人

把整个文件夹（或不含 `_libs` 的 6 个源码文件）压缩成 zip，通过微信/QQ/邮件发出去即可。对方收到后：

1. 解压到任意文件夹；
2. 电脑装有 Python 3.10+（安装时勾选 Add python.exe to PATH）；
3. 双击 `run.cmd`——首次会自动联网安装 streamlit、sympy、numpy、matplotlib 四个免费库，之后离线可用。

如果对方没有网络或不想装库，可以连 `_libs` 文件夹一起打包（约 500 MB），适合网盘或 U 盘；`run.cmd` 检测到 `_libs` 会优先使用它，全程不联网。
程序服务只监听对方电脑本机（localhost），转发不会暴露给局域网其他人。

## 使用提醒

这是学习辅助工具。Python 给出的答案可以用来核对，但解题步骤仍需手算练习——考试的卷子上没有电脑。
